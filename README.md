# Concept Generator

Text-only MVP scaffold for exploring multiple product concept directions from one brief.

## Stack

- Next.js App Router
- React with JSX
- Zod

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`

## Current State

- App shell and core screens are scaffolded
- API routes are stubbed with mock structured responses
- Prompt asset placeholders live in `lib/concept-generator/prompts/`
